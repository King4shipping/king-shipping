# King Shipping

واجهة أولية عربية لإدارة عمليات شركة شحن، تعمل مباشرة من المتصفح.

## التشغيل

افتح `index.html` في متصفح حديث، أو انشر المستودع باستخدام GitHub Pages.

## الوظائف الحالية

- لوحة مؤشرات للشحنات والتحصيل.
- إنشاء بوليصة شحن، البحث والتصفية، وتحديث حالة الشحنة.
- طباعة البوليصة من المتصفح.
- عرض أسعار 27 محافظة مصرية وتعديل أسعار الشحن والمرتجعات.
- صفحات حسب الدور: الإدارة، التاجر، والمندوب.
- حفظ البيانات في `localStorage` على الجهاز الحالي.

## حسابات العرض التجريبية

- `admin` / `123456`
- `merchant` / `123456`
- `courier` / `123456`

> تنبيه: هذه نسخة واجهة تجريبية وليست نظاماً إنتاجياً. تسجيل الدخول وبيانات الشحن محفوظة محلياً في المتصفح، ولا توفر مصادقة حقيقية أو مزامنة بين الأجهزة. لا تستخدم بيانات حقيقية أو حساسة قبل ربط التطبيق بخادم وقاعدة بيانات وتأمين صلاحيات المستخدمين.
